# محاكي المصنع — Android Alpha

مشروع Godot 4.3 لمحاكي مصنع ثلاثي الأبعاد.

## بناء APK بدون كمبيوتر
1. ارفع محتويات هذا المشروع إلى GitHub.
2. افتح تبويب **Actions**.
3. اختر **Build Android APK**.
4. اضغط **Run workflow** (أو اعمل Push إلى `main`).
5. بعد نجاح البناء افتح الـWorkflow وانزل إلى **Artifacts**.
6. حمّل `FactorySim-Android-APK` وفك الضغط عن ملف الـAPK ثم ثبته على هاتف Android.

> هذا APK تجريبي Debug، وليس إصدار متجر نهائيًا.
